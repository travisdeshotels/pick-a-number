# Pick A Number API

## Stack used
* SQLITE
* Python
* fastapi

## Running the API
1. `make builddb` to set up the SQLITE database. Output file is `game.db`.
2. `export SQLITE_DB=/path/to/your/game.db` to set your database file path.
3. `make run` to start the server.
